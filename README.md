# quan-amd-miner

An AMD GPU miner for Quantus, currently in development and testing.

quan-amd-miner is independently developed AMD GPU mining software for Quantus and is not an official Quantus Network project.

## Current status

- The initial focus is Quantus mining on AMD GPUs.
- Windows and Ubuntu test builds are undergoing validation.
- Pool testing is underway on the Kryptex QTC pool. The current Ubuntu test rig uses six RX 6700 XT GPUs and identifies itself as `quan-amd-miner/0.1.0`.
- Public downloads are not available yet. A release date has not been announced.

Test results and supported GPU/driver combinations are still being checked. Further updates will be posted here as testing progresses.

## Questions and feedback

- Questions, GPU requests and general feedback: [Discussions](https://github.com/amdpowgit/quan-amd-miner/discussions).
- Reproducible bugs after public builds are available: [Issues](https://github.com/amdpowgit/quan-amd-miner/issues).

When requesting GPU support, please include your GPU model and operating system.

## Earlier test name

Earlier development builds appeared in pool statistics as **AMD_POW-Miner**. This project is now being prepared under the name **quan-amd-miner**.
